Limitime 개인정보 처리방침

日本語　/　English

1. 소개

본 개인정보 처리방침은 Limitime(이하 "본 앱")에서 이용자 정보의 수집, 이용, 저장 및 외부 서비스 전송에 관한 사항을 설명합니다.

본 앱은 호환되는 궐련형 전자담배 기기의 사용 현황을 기록하고, 목표 설정과 잠금·잠금 해제 기능을 통해 흡연량 감소를 지원하기 위해 아래 정보를 처리합니다.

2. 수집 또는 생성하는 정보

본 앱이 현재 수집하거나 생성하는 정보는 다음과 같습니다.

  • Supabase 익명 인증으로 발급되는 이용자 식별자 및 기기에 저장되는 인증 세션 정보
  • Bluetooth 검색 및 연결 과정에서 얻는 호환 기기의 식별자, 표시 이름, 신호 강도, 연결 상태, 광고 데이터, 지원 Service 및 Characteristic 정보
  • 호환 기기에서 얻는 누적 사용 횟수, 잠금 상태 및 홀더형 호환 기기의 홀더 수납 상태
  • Bluetooth 연결 해제·재연결 시각, 홀더형 호환 기기에서 사용 횟수가 정확히 1회 증가한 것으로 확인된 경우의 홀더 분리·재수납 시각, 이전 및 현재 누적 횟수와 각 횟수의 확인 시각, 두 횟수의 차이
  • 흡연량 감소 시작 전의 하루 평균 흡연 개수, 일일 목표 개수, 최소 대기 시간, 담배 한 갑의 가격 및 흡연량 감소 기능의 이용 상태
  • 예정 시각보다 일찍 잠금을 해제한 시각과 이용자가 선택한 사유. 사유 입력을 건너뛴 경우에는 해당 사유를 저장하지 않습니다.
  • 이용약관 및 개인정보 처리방침 동의 여부, 각 문서의 버전, 동의 일시 및 동의 당시의 앱 버전
  • 초기 설정에서 표시한 화면과 연결 절차의 하위 단계, 완료 조작, Bluetooth 준비·기기 검색·연결·설정 저장의 성공 또는 실패, 설정 완료, 각 이벤트의 발생 시각, 설정 시도 식별자 및 앱 버전
  • Live Activities 표시 설정, 설치별 임의 식별자, 잠금 주기별 임의 식별자, 기기 종류, 잠금 시작·해제 예정 시각, 표시 상태 및 Apple Push Notification service(APNs)에서 Live Activities를 시작·종료하는 데 사용하는 토큰
  • 초기 설정 완료 상태, 잠금 주기 시작 시각, 적용 중인 최소 대기 시간, 확인된 잠금 해제 실패 횟수 등 앱 상태 유지에 필요한 정보

3. 정보 이용 목적

수집한 정보는 다음 목적으로만 이용합니다.

  • 호환 기기의 검색, 연결, 재연결, 상태 표시, 잠금 및 잠금 해제
  • 사용 횟수, 사용 간격, 목표 달성 현황 및 예상 절약 금액의 기록과 표시
  • 최소 대기 시간 및 조기 잠금 해제 등 이용자가 설정한 흡연량 감소 지원 기능 제공
  • 기기에 저장된 데이터 복원 및 기기와 Supabase 간 데이터 동기화
  • 잠금 화면과 Dynamic Island에 대기 시간을 표시하고, 대기 시간이 끝나면 이용자가 앱을 열어 잠금을 해제할 수 있도록 하는 Live Activities 기능 제공
  • 이용약관 및 개인정보 처리방침 동의 이력 관리
  • 초기 설정 중 이탈·실패 지점 집계 및 설정 절차 개선
  • 연결 실패 또는 잘못된 응답 등 앱의 정상 작동 확인과 개발 중 오류 조사

4. Bluetooth 이용

본 앱은 Bluetooth Low Energy를 사용하여 호환 기기를 검색하고 연결합니다. 검색 과정에서 기기 식별자, 표시 이름, 신호 강도, 연결 가능 여부, 송신 출력, Service UUID, Manufacturer Data, Service Data 등의 광고 정보를 일시적으로 수집할 수 있습니다. 이러한 정보는 호환 기기 판별, 연결 및 개발 중 작동 확인에 사용합니다.

연결 후 지원 Service와 Characteristic을 확인하고 기기에서 전달하는 알림 데이터를 분석하여 누적 사용 횟수, 잠금 상태 및 홀더형 호환 기기의 홀더 수납 상태를 확인합니다. 원본 홀더 수납 상태는 누적 사용 횟수를 확인하는 계기로만 일시적으로 사용합니다. 홀더를 분리한 뒤 누적 사용 횟수가 정확히 1회 증가한 것으로 확인된 경우에만 분리·재수납 시각을 사용 시작·종료의 추정 구간으로 기기에 저장하고 Supabase에 전송합니다. 본 앱에는 배터리 정보를 수집하는 기능이 구현되어 있지 않습니다.

연결에 성공한 기기의 식별자와 표시 이름은 이후 재연결을 위해 기기에 저장합니다. 사용 횟수의 차이를 확인한 경우 해당 기록과 함께 기기 표시 이름을 Supabase에 전송합니다. Ploom의 표시 이름은 개별 기기 접미사를 제외한 모델명인 "Ploom AURA" 또는 "Ploom CUBE"로 통일합니다. 신호 강도, Manufacturer Data, Service Data, 송신 출력, 연결 가능 여부, Service UUID, Characteristic 정보 및 수신한 원본 알림 데이터는 일반적인 앱 데이터로 저장하거나 Supabase에 전송하지 않습니다. 다만 개발용 빌드에서는 조사 목적으로 기기 로그에 출력될 수 있습니다.

본 앱은 Bluetooth를 사용하지만 위치 정보를 수집하는 기능이나 위치 정보 권한 요청은 구현되어 있지 않습니다.

5. 데이터 저장

본 앱은 기기 내부와 Supabase에 저장하는 데이터의 역할을 구분합니다.

기기 내부의 AsyncStorage에는 초기 설정 완료 상태, 전송되지 않은 설정 진행 이벤트와 설정 시도 식별자, 법적 문서 동의 정보와 미전송 동의 기록, 흡연량 감소 설정 및 기능 이용 상태, 연결된 기기의 식별자와 표시 이름, 누적 사용 횟수의 기준값, 연결 해제·재연결 또는 확인된 홀더 분리·재수납 관련 시각, 확인된 사용 횟수 차이 기록과 미전송 기록, 잠금 주기, 조기 잠금 해제 시각·사유·미전송 기록, Supabase 익명 인증 세션을 저장합니다. AsyncStorage는 암호화된 저장 영역이 아닙니다.

Live Activities의 표시 설정과 현재 잠금 주기, 중복 방지용 식별 정보 및 종료 대기 중인 잠금 주기 식별자(최대 64개)도 기기 내부에 저장합니다. APNs 토큰은 기기의 AsyncStorage에 저장하지 않고 서버에서 관리합니다. 서버의 Live Activities 정보에는 Bluetooth 기기의 개별 식별자나 표시 이름을 포함하지 않습니다.

Supabase에는 익명 이용자 식별자와 연결하여 초기 설정 화면 도달 정보, 연결 절차의 하위 단계 표시·완료 정보, 처리 결과 이벤트, 사용 횟수 차이의 구간과 이전·현재 누적 횟수 확인 시각, 조기 잠금 해제 시각과 선택 사유, 이용약관 및 개인정보 처리방침 동의 이력을 저장합니다. 누적 횟수 확인 시각은 날짜별 사용 개수를 집계하는 데 사용하며, 알 수 없는 시각은 추정하지 않습니다. IQOS의 사용 횟수가 1회 증가했고 시작 시각을 확인할 수 있는 경우, ONE 모델의 Bluetooth 연결 해제 시각 또는 i / PRIME 모델의 홀더 분리 시각을 시작 시각의 추정값으로 저장·전송하여 해당 날짜에 포함합니다. 초기 설정 이벤트에는 Bluetooth 기기의 식별자, 흡연량 감소 설정값 또는 기술적인 오류 상세 내용을 포함하지 않습니다. 사용 구간은 기종에 따라 연결 해제부터 재연결까지, 또는 사용 횟수가 1회 증가한 것으로 확인된 홀더 분리부터 재수납까지로 설정합니다. 홀더 시각은 실제 가열 시작·종료를 직접 측정한 값이 아니라 추정값이며, 누적 횟수 차이가 여러 회인 경우 하나의 구간을 여러 번의 사용으로 배분하지 않습니다.

6. 외부 서비스

본 앱은 익명 인증, 데이터베이스 및 데이터 동기화를 위해 Supabase를 사용합니다. Supabase와 통신할 때는 기기에 저장된 인증 토큰을 사용합니다. 통신 과정에서 Supabase가 IP 주소 등의 통신 정보를 처리할 수 있지만, 본 앱은 IP 주소를 자체 데이터베이스 항목으로 저장하지 않습니다. Supabase의 정보 처리에는 해당 회사의 개인정보 처리방침 및 기타 조건이 적용됩니다.

Live Activities가 활성화된 경우 시작·종료용 APNs 토큰, 임의의 설치·잠금 주기 식별자, 기기 종류, 잠금 시작·해제 예정 시각 및 표시 상태를 Supabase에 전송합니다. Supabase는 Apple의 APNs에 토큰과 표시용 기기 종류, 시각, 잠금 주기 식별자, 앱으로 연결되는 링크를 전송합니다. Apple의 정보 처리에는 해당 회사의 조건이 적용됩니다. 설정에서 Live Activities를 비활성화하면 현재 표시를 종료하고 이후 잠금 시 표시를 시작하지 않습니다.

본 앱은 초기 설정 절차 개선에 필요한 진행 이벤트를 Supabase에 전송합니다. 광고 게재, 충돌 보고 또는 제3자 광고 추적을 목적으로 하는 SDK는 포함되어 있지 않습니다.

7. 제3자 제공

운영자는 법령에 따른 경우, 생명·신체·재산의 보호에 필요한 경우 및 기타 법령상 허용되는 경우를 제외하고 이용자 정보를 부당하게 제3자에게 제공하거나 판매하지 않습니다.

Supabase로의 전송은 본 앱의 인증 및 데이터 저장 기능을 제공하기 위한 외부 서비스 이용이며, 광고를 목적으로 한 정보 판매가 아닙니다.

8. 데이터 보관 기간 및 삭제

기기 내부의 확인된 사용 횟수 차이 기록은 최대 2,000건까지 보관합니다. 미전송 사용 횟수 차이 기록은 최대 500건이며 재연결 확인 시각부터 10일 동안 보관합니다. 미전송 초기 설정 진행 기록은 최대 100건, 미전송 조기 잠금 해제 기록은 최대 500건, 미전송 동의 기록은 1건을 보관하며 전송이 완료되면 미전송 상태를 삭제합니다. 기타 기기 내부 설정은 변경 시 덮어쓰거나 앱을 삭제할 때까지 보관합니다.

Supabase의 Live Activities 잠금 주기 정보와 주기별 토큰은 종료 후 24시간이 지난 다음 실행되는 매시간 삭제 작업에서 제거합니다. 시작 후 8시간이 지난 잠금 주기는 종료된 것으로 처리하며, 90일 동안 갱신되지 않은 설치 정보와 시작용 토큰도 매시간 삭제 작업에서 제거합니다.

설정 화면의 "모든 데이터 삭제" 기능을 사용하면 기기 내부의 앱 데이터, 서버에 저장된 초기 설정 진행 정보·사용 횟수 차이 기록·조기 잠금 해제 기록·동의 이력, Live Activities 정보와 토큰 및 익명 인증 이용자를 삭제할 수 있습니다. 이 작업은 취소할 수 없으며 인터넷 연결이 필요합니다. 삭제가 완료되면 앱은 초기 설정 시작 화면으로 돌아갑니다.

삭제에 실패한 경우 네트워크 연결을 확인한 후 설정 화면에서 다시 시도해 주세요. 서버 측 삭제가 성공하기 전에는 기기 내부 데이터와 인증 세션을 삭제하지 않습니다.

9. 보안

운영자는 처리하는 정보에 대한 무단 접근, 유출, 변조 또는 손실을 방지하기 위해 합리적인 안전 관리 조치를 시행합니다.

Live Activities용 토큰과 잠금 주기 정보는 앱에서 데이터베이스에 직접 등록하거나 조회하지 못하도록 제한합니다. 인증된 이용자의 요청을 검증하는 서버 처리만 해당 정보를 조작할 수 있으며, APNs 비밀키는 앱에 포함하지 않습니다.

Supabase의 각 데이터에는 익명 이용자 식별자를 설정하고 Row Level Security를 적용하여 앱에서는 현재 인증된 이용자 자신의 데이터만 등록·조회할 수 있도록 제한합니다. 다만 모든 통신 및 저장 방식의 완전한 안전성을 보장할 수는 없습니다.

10. 미성년자 이용 제한

본 앱은 궐련형 전자담배 사용과 관련된 기능을 제공하므로, 각 국가 또는 지역에서 관련 법령상 담배를 사용할 수 없는 미성년자를 대상으로 하지 않습니다. 일본에서는 20세 미만의 이용을 대상으로 하지 않습니다. 대한민국에서는 청소년 보호 관련 법령에 따라 담배 구매가 허용되지 않는 청소년을 대상으로 하지 않습니다.

현재 앱에는 생년월일 입력이나 신분증을 이용한 연령 확인 기능이 구현되어 있지 않습니다.

11. 개인정보 처리방침 변경

운영자는 법령, 앱 기능 또는 정보 처리 방식의 변경에 따라 본 방침을 변경할 수 있습니다. 중요한 변경 사항은 앱 내부 또는 기타 적절한 방법으로 안내합니다.

12. 문의

본 방침, 이용자 정보 또는 데이터 삭제에 관한 문의는 앱의 "설정" 메뉴를 이용하거나 limitime.support@gmail.com으로 연락해 주세요.

앱에서 문의 기능을 사용하면 기기의 메일 앱이 열리고 본문에 앱·운영체제 정보, 기존 이용자 식별자를 기반으로 만든 지원용 ID 및 선택한 기기 이름이 추가됩니다. 전송 여부는 이용자가 결정하며 전송 전 본문을 수정하거나 삭제할 수 있습니다. 인증 토큰, Bluetooth 기기의 개별 식별자 및 원본 통신 로그는 본문에 포함되지 않습니다.

운영자는 문의에 답변하고 오류를 조사하기 위해 발신자의 이메일 주소와 문의 내용을 처리합니다. 지원용 ID가 포함된 경우 해당 ID와 연결된 저장된 사용 기록을 확인할 수 있습니다. ID 공유를 원하지 않으면 이메일을 보내기 전에 본문에서 삭제해 주세요.
